# 🌊 Marine AI

Agentic AI-powered Marine Intelligence Platform for conversational
access to marine, weather, oceanographic and geospatial information.

## Project Structure

- frontend/ - React frontend
- backend/ - Node.js/Express backend
- ai/ - Agentic AI and orchestration
- gis/ - Geospatial processing
- risk-engine/ - Marine risk and route optimization
- data/ - Sample and processed datasets
- docs/ - Project documentation
