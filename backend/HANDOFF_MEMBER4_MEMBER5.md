## 1. Interface for Member 4 (Risk Engine & Route Costing)

### A. Geofence Check Functions (`frontend/src/gis/geofence.js`)

Member 4 can import these functions directly to apply geofence hazard penalties to route cost algorithms:

```javascript
import { checkPointGeofence, checkRouteGeofence } from './gis/geofence.js';

// 1. Check if a single coordinate is inside a restricted demo polygon
const pointResult = checkPointGeofence(lat, lon);
// Returns: { isInside: boolean, status: "BLOCKED" | "ALLOWED", zone: object, warningMessage: string, isDemoBoundary: true }

// 2. Check if a proposed vessel route crosses restricted demo polygons
const waypoints = [{ lat: 16.98, lon: 82.24 }, { lat: 16.80, lon: 82.35 }, { lat: 16.82, lon: 82.62 }];
const routeResult = checkRouteGeofence(waypoints);
// Returns: { crossesRestricted: boolean, status: "ROUTE_HAZARD_WARNING" | "ROUTE_SAFE", breachedZones: array, warningMessage: string }
```

### B. Risk-Grid GeoJSON Layer (`frontend/src/gis/layers/riskGridLayer.js`)

Member 4 can generate or pass risk grid cells to the map layer:

```javascript
import { createRiskGridGeoJSON } from './gis/layers/riskGridLayer.js';

const riskGridData = createRiskGridGeoJSON(minLat, maxLat, minLon, maxLon, step);
// Returns standard GeoJSON FeatureCollection containing 0.25° x 0.25° grid cells with properties:
// { gridId, centerLat, centerLon, riskScore (0-100), riskCategory, waveHeightM, windSpeedKnots, color }
```

## 2. Interface for Member 5 (Frontend UI & Map Visualization)

### A. Map Component (`frontend/src/components/MarineMap.jsx`)

Member 5 can render the full GIS map component using standard props:

```jsx
<MarineMap
  userLocation={{ lat: 16.98, lon: 82.24 }}
  pfzList={pfzArray}
  nearestPfz={nearestPfzObj}
  activeCategory="ALL"
  onSelectCategory={(cat) => setActiveCategory(cat)}
  onSelectPfz={(pfz) => setSelectedPfz(pfz)}
  routeObj={routeGeoJSONObj}        // Generated by createRouteGeoJSON(waypoints)
  riskGridGeoJSON={riskGridGeoJSON} // Generated by createRiskGridGeoJSON()
  showRiskGrid={true}
  showGeofences={true}
  showRoute={true}
/>
```

### B. GeoJSON Coordinate Ordering Rule

- **API Coordinate Format**: `{ lat: 16.98, lon: 82.24 }`
- **GeoJSON Coordinate Spec**: `[longitude, latitude]` -> `[82.24, 16.98]`
- All GeoJSON generators (`pfzLayer.js`, `geofenceLayer.js`, `riskGridLayer.js`, `routeLayer.js`) handle this conversion automatically.
