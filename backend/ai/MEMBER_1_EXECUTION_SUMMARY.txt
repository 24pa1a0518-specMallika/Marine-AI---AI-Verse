3. FILES OWNED & BUILT BY MEMBER 1
--------------------------------------------------------------------------------
Location: sih2026/ai/

• ai/orchestrator.js
  - Main pipeline entry point: processQuery(userQuery, options, initialContext).
  - Coordinates Intent -> Planner -> Tools -> Context -> Synthesis.

• ai/prompts.js
  - System prompt templates for Intent Agent, Task Planner Agent, and Synthesis Agent.
  - Enforces strict JSON schemas for model outputs.

• ai/agents/intentAgent.js
  - Classifies query into one of 7 intents:
    1. PFZ_SEARCH (Potential Fishing Zone lookups)
    2. MARINE_SAFETY (Safety check & trip feasibility)
    3. SAFE_ROUTE (Navigation paths avoiding hazards)
    4. MARINE_CONDITIONS (Weather, waves, SST, wind metrics)
    5. GEOFENCE_CHECK (Maritime boundaries, IMBL, restricted areas)
    6. HAZARD_ALERT (Cyclone alerts, high wave emergency warnings)
    7. GENERAL_QUERY (System capabilities & non-maritime questions)
  - Outputs required parameters: locationRequired, timeRequired, destinationRequired, language (en/te).
  - Includes deterministic fallback for offline/no-API-key execution.

• ai/agents/plannerAgent.js
  - Translates intent into task sequences:
    - PFZ_SEARCH    --> ["getNearbyPFZ"]
    - MARINE_SAFETY --> ["getWeather", "getOceanConditions", "getWarnings", "calculateRisk"]
    - SAFE_ROUTE    --> ["getNearbyPFZ", "getRiskMap", "checkGeofence", "findSafeRoute"]
    - MARINE_CONDITIONS --> ["getWeather", "getOceanConditions", "getWarnings"]
    - GEOFENCE_CHECK --> ["checkGeofence"]
    - HAZARD_ALERT  --> ["getWarnings", "calculateRisk"]
    - GENERAL_QUERY --> []

• ai/tools.js
  - Thin HTTP wrapper calling backend endpoints (e.g. http://localhost:5000/api/...).
  - Features quick timeout fallback:
    - Connected backend --> returns data tagged "[LIVE_DATA]"
    - Offline backend   --> returns deterministic sample data tagged "[DEMO_MOCK]"

• ai/contextManager.js
  - Maintains state across turns:
    - lastLocation (e.g., Visakhapatnam Coast)
    - destination
    - selectedPFZ
    - previousRiskResult

• ai/agents/synthesisAgent.js
  - Combines tool data, context, and intent into a structured output:
    - answer (natural language explanation in English or Telugu)
    - recommendation (SAFE_TO_SAIL | PROCEED_WITH_CAUTION | DO_NOT_SAIL | NAVIGATION_ADVISORY | INFORMATIONAL)
    - evidence: { source, timestamp, parametersUsed, riskFactors }

• ai/test.js
  - Comprehensive automated test suite with 8 test cases.
